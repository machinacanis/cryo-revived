# 06 错误码

## 1. 判定规则

- 业务成败以响应 JSON 的 `err_code`（或 `code`）为准；`message` 仅用于人工排查，随时会变。
- 链路追踪：响应头 `X-Tps-trace-ID` 或 body `trace_id`，提工单/排查时附带。

## 2. HTTP 状态码

| 值 | 含义 |
|---|---|
| 200 | 成功 |
| 201/202 | 异步操作成功（仍可能返回 error body，需特殊处理） |
| 204 | 成功无包体（删除类） |
| 401 | 认证失败 |
| 404 | API 不存在 |
| 405 | 方法不允许 |
| 429 | 频率限制 |
| 500/504 | 处理失败 |

## 3. 公共错误码（err_code）

| 值 | 含义 | 建议 |
|---|---|---|
| 11201 | 鉴权失败（实测：无 token / token 无效，HTTP 401，`err_code=40012001`） | 检查/刷新 token |
| 10001 | UnknownAccount 账号异常 | - |
| 10003 | UnknownChannel 子频道异常 | - |
| 10004 | UnknownGuild 频道异常 | - |
| 11251/11261 | appid 错误/缺失（token 错） | 检查凭证 |
| 11252 | 检查应用权限失败（系统错误） | 可重试一次 |
| 11253 | 接口权限未开通 | 向平台申请 |
| 11254 | 接口被封禁 | - |
| 11262 | 该接口不支持 Bot Token 调用 | - |
| 11281 | 检查管理员失败（系统错误） | 可重试一次 |
| 11282 | 需要管理员权限（用户未授权） | 引导授权 |

## 4. access_token 接口错误码

见 [01-authentication.md](01-authentication.md)：100001 频控 / 100007 appid invalid / 100016 凭证错误 / 10004 机器人不存在。

## 5. 消息发送错误码（单聊/群聊共用段）

| err_code | 含义 |
|---|---|
| 22006 | msg_type 与内容不匹配 |
| 304061 | 消息内容无效 |
| 304080 | 文件信息（file_info）无效 |
| 304103 / 40034005 | msg_id 已过期不能回复 |
| 40034006 | 消息内容违规 |
| 40034008~11 | markdown 参数空值/含换行/含语法/无效 |
| 40034024~27 | msg_id/event_id 无效、过期或事件不支持回复 |
| 40034029 | 内联键盘行列超限 |
| 40034100 | 主动消息超频控 |
| 40034105 | 主动消息无权限 |
| 40034122~23 | 召回消息达上限/不支持 |
| 40034127 | 无 markdown 模板权限 |
| 40034128 | 被动回复超时/超次数 |
| 40054005 | 消息被去重（msg_id+msg_seq 重复） |
| 40054007 / 40054018 | 消息长度超限 |
| 40054013 | 用户拒收消息 |
| 40054016 | 机器人已下线 |
| 50055001/2 | 发送异常，稍后重试 |

单聊特有：50059 输入类型错、40054004 无好友关系、40054006 好友关系验证失败。
群聊特有：305007 键盘样式错、340069 消息类型无效、40034101/40054003 机器人非群成员、40054002 机器人被禁言、40054010 不允许发 URL。
频道特有（旧接口）：消息需通过 MESSAGE_AUDIT 审核；主动消息 20 条/子频道/天限制。
互动响应（PUT /interactions）：630001~630008（参数/appid/interaction 处理类）。

## 6. WebSocket 关闭码

见 [04-events-gateway.md](04-events-gateway.md) §5.3：4001/4002 参数错不可重试；4006/4007 重新 Identify；4008/4009 可 Resume；4010~4014 配置/权限错；4900~4913 内部错误重连 Identify；4914/4915 下架/封禁不可连。

## 7. 重试策略建议（SDK）

- `429`、5xx、`11252/11281` 类系统错误：指数退避重试（≤3 次）。
- `40054005` 去重：递增 `msg_seq` 后重发。
- `304103/40034005` 过期：不可重试，转主动消息或放弃。
- 401：强制刷新 access_token 后重试一次。
- 记录 `trace_id` 到日志，便于向平台反馈。
